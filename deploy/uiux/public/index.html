نصب و استفاده در کد

  • Cloud: اسکیل در .cursor/skills/ ریپو است
  • Global: npx ui-ux-pro-max-cli init --ai cursor --global
  • جستجو: اجرای search.py --design-system
  • ذخیره: فلگ --persist برای design-system/
  • استک: --stack react|nextjs|tailwind
python3 .cursor/skills/ui-ux-pro-max/scripts/search.py "SaaS fintech dashboard dark" --design-system -p "MyApp"
۲

پرامپت برای داشبورد

  • نوع محصول + صنعت + کلمات کلیدی
  • درخواست design system قبل از کد
  • ذکر استک پروژه (React, Next, …)
  • تعداد ویجت و نقش کاربر
با ui-ux-pro-max یک داشبورد آنالیتیکس SaaS بساز.
اول search.py --design-system اجرا کن.
شامل: sidebar، KPI cards، نمودار خطی، جدول تراکنش‌ها.
استک: Next.js + shadcn/ui + Tailwind. تم تیره.

  • از --domain landing|ux|chart استفاده کنید

🔑 کد فعال‌سازی — اسکیل را به چت اضافه کنید

متن زیر را کپی کرده و در اولین پیام هر چت Cursor (یا Cloud Agent) بچسبانید تا اسکیل فعال شود:

@ui-ux-pro-max

از این چت به بعد از اسکیل ui-ux-pro-max برای تمام تصمیمات UI/UX استفاده کن.

قوانین:
1. قبل از نوشتن UI، حتماً design system بگیر:
   python3 .cursor/skills/ui-ux-pro-max/scripts/search.py "<product> <industry> <keywords>" --design-system -p "<Project>"
2. برای جزئیات: --domain style|color|typography|ux|landing|chart
3. برای استک پروژه: --stack react|nextjs|html-tailwind|shadcn
4. دسترسی‌پذیری WCAG AA، موبایل‌اول، و بدون emoji به‌جای آیکون

اگر اسکیل در دسترس نیست، نصب کن:
npx ui-ux-pro-max-cli init --ai cursor --global

یا با یک خط کوتاه:

/ui-ux-pro-max از design-system شروع کن و یک [داشبورد SaaS / لندینگ فروشگاه / صفحه checkout] با Tailwind بساز
